# Forensic Artifact Recovery from Disk Image

## Ethical and Legal Considerations

This repository contains the project report and forensic artifacts from a disk image as part of a digital forensics investigation. The project was conducted for academic purposes and involved recovering and analyzing forensic artifacts to reconstruct user activity, following established forensic methods. The disk image itself was never modified.

Artificial Intelligence was used as a supportive tool to assist with organizing data, but all analyses and interpretations were performed and verified manually. The use of Artificial Intelligence was combinated with manual adjustments to ensure the correct chronological order of events and to verify the accuracy of the results. This approach ensured both efficiency and accuracy while maintaining ethical handling of the digital evidence. All materials in this repository are provided for educational purposes only and should not be used for illegal or unauthorized activities.
